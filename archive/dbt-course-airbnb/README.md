# Attributed dbt course references

These seven SQL model files came from the supplied copy of the **Complete dbt Bootcamp** learning material associated with **Zoltan C. Toth / Nordquant**. They are retained as course exercises and references, not presented as an independently invented Airbnb platform.

The supplied upstream README links to the [course](https://www.udemy.com/course/complete-dbt-data-build-tool-bootcamp-zero-to-hero-learn-dbt/). Its supplied **CC BY-NC-SA 4.0** license is preserved in [LICENSE.md](LICENSE.md) and applies to this course material. This folder does not relicense the rest of the portfolio.

The source references an external Snowflake AIRBNB.RAW schema. Original data, profiles, account details, build artifacts, orchestration settings and deployment workflows are excluded. These are source references; this folder is not claimed to be a standalone tested service. Use `projects/customer-analytics/` for the runnable synthetic dbt study.
